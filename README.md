## 1. Mục tiêu
Hệ thống hỗ trợ nhân viên cửa hàng tiếp nhận nhanh chóng và chính xác các yêu cầu bảo hành từ khách hàng. Chức năng lõi bao gồm tra cứu hồ sơ khách hàng, ghi nhận tình trạng thiết bị, tự động đối chiếu hạn bảo hành, phân loại mức độ sự cố và tự động tính toán hạn cam kết trả máy nhằm chuẩn hóa quy trình và nâng cao chất lượng dịch vụ.
